# Giloo Labs Prototype

This is the prototype for the new Giloo Labs film page design.

## Features
- **Semantic HTML5 & BEM CSS**: Clean, maintainable structure.
- **Responsive Design**: Mobile-friendly layout with specific Desktop/Mobile behaviors (e.g., sticky sidebar).
- **Interactive Elements**: Custom video modal, sticky header on scroll.
- **SEO Privacy**: Configured to prevent search engine indexing (`noindex`, `robots.txt`, `vercel.json`).

## Project Structure
- `index.html`: Main entry point.
- `styles.css`: All styles using CSS variables for design tokens.
- `script.js`: Interactive logic (Modal, Header scroll).
- `robots.txt`: SEO configuration.
- `vercel.json`: Deployment configuration.

## Development
Open `index.html` in any modern browser to view the prototype.
